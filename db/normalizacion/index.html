1️⃣ Primera Forma Normal (1FN)

El objetivo: Lograr atomicidad. Cada celda debe tener un solo valor. ¡Adiós a las listas y múltiples datos amontonados!

❌ Problema: Hay listas y varios valores mezclados en una sola línea.
ID Piloto Lenguaje Instructor Aula
1 Max Verstappen Java, Python García, Fernán A1, B2

¡Solución aplicada! Cada lenguaje se separa en su propia fila independiente:

ID Piloto Lenguaje (Atómico) Instructor Aula
1 Max Verstappen Java García A1
1 Max Verstappen Python Fernán B2

2️⃣ Segunda Forma Normal (2FN)

El objetivo: Eliminar dependencias parciales y claves compuestas repetitivas. Separamos los datos de los pilotos por un lado y los lenguajes/cursos por el otro.

❌ Problema: Nombres de pilotos y datos se repiten constantemente.
ID_Piloto Piloto Lenguaje Instructor
1 Max Verstappen Java García

¡Solución! Dividimos en la tabla Pilotos y la tabla Lenguajes:

Tabla: Pilotos

ID Piloto
1 Max Verstappen

Tabla: Lenguajes (con FK)

ID_Piloto Lenguaje Instructor
1 Java García

3️⃣ Tercera Forma Normal (3FN)

El objetivo: Eliminar dependencias transitivas (cuando un campo depende de otro que no es la clave principal, como el instructor o el aula dependiendo del lenguaje).

❌ Problema: El instructor y el aula dependen indirectamente del lenguaje.
